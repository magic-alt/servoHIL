## 电气检查与有意修改的边界

`repair/corrected-baseline.xml` 是单独安全修复后的真实原生网表。之后的所有视觉整理保持：

- 216 个网表组件（包括原有非 # 位号的标记组件）；
- 193 个实际 pin 连接分组；
- 747 个 pin 项；
- 器件 Value 与 Footprint 不变；
- 标签变更前后实际 pin 分组完全相同。

不能笼统声称与原 main 完全等价，因为本 PR 独立修复了原 main 已有的问题：

1. U408.6 原来接 INPUT_OK，与仓库自己的 disarm 规则矛盾；改为 HIL_ARM，使主机撤销 ARM 时直接保持 DAC reset。
2. 原 U409 状态输出方案换为 Q401/Q402 主机参考偏置的状态电路；这是原 finalization 计划未落到源文件的修复，不是绘图美化。
3. 采用实际封装来源并修正 C105 的封装选择；同样作为独立 repair 提交记录。

`repair/intentional-delta.json` 记录这一差异。之后的 style/polish 阶段以修复后的同一电路为基准，未再修改电气连接或数值。

## 可编辑性

所有器件 Value 显示为原生属性，保留完整原值，避免用复制/截断的静态文本导致用户修改后图纸与器件属性不一致。符号、引脚、UUID、封装和工程路径保留。`READABILITY_PROGRESS.json` 是历史记录，不会在普通构建时重画工程。

## 验证范围

实际运行：原生 XML、连接等价、独立电源/DAC/载板断言、原生 ERC，以及 local/global 作用域、重复位号、可编辑字段和图框锚点检查。PDF 和 PNG 已导出供审阅。

**逐页人工视觉签核尚未完成。** 本轮执行环境无法打开新导出的栅格预览，因此不将自动导出或几何检查写成“人工看过每一页”。请结合 PDF/PNG 与 KiCad 原生工程进行最终视觉审阅；自动检查不保证所有文本/线路视觉间距完美。

电气 ERC/网表通过也不等于硬件 qualification：独立 watchdog、AO disconnect、完整 DUT inhibit、ADC/PHY、动态电源、负载稳定性、掉电反灌、Vivado 时序与 FOC 实测仍按原门禁推进。没有 PCB layout 或硬件放行。
